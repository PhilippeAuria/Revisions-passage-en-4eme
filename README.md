# Revisions-passage-en-4eme

Application de révision pour les élèves de 5ème préparant leur passage en 4ème, en mathématiques.

## Description

Application web autonome (un seul fichier HTML, utilisable hors ligne) organisée par chapitres du programme de 5ème. Chaque chapitre propose un rappel de cours synthétique puis un QCM auto-corrigé, avec suivi de la progression de l'élève (nombre de questions vues et réussies).

## Fonctionnalités

- Parcours par chapitres, avec rappel de cours avant chaque série de questions.
- QCM auto-corrigés avec retour immédiat (correct/incorrect) et explication.
- Suivi de progression par chapitre (questions vues / réussies / total).
- Mode sombre / mode clair.
- Fonctionne entièrement hors ligne, sans installation.

## Utilisation

Ouvrir simplement `index.html` dans un navigateur, aucune dépendance ni connexion internet requise après téléchargement.
